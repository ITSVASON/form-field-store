# Form & Field

A small, responsive ecommerce storefront demo built with plain HTML, CSS, and JavaScript.

## Run locally

From the project folder, start a local web server:

```sh
python -m http.server 8765 --bind 127.0.0.1
```

Then open <http://127.0.0.1:8765>.

## Project files

- `index.html` contains the storefront structure.
- `styles.css` contains the responsive presentation.
- `app.js` contains the sample product data and storefront interactions.

Product imagery is loaded from Unsplash. The shopping bag is a browser-side demo, and checkout is a placeholder; this project does not process payments or orders.
